# Haiku Messenger mobile

React Native CLI project (no Expo). From the repository root, install the root npm workspace, then run `npm run dev:mobile`. See the repository `README.md` for setup and platform requirements.

Copy `.env.example` to `.env` and set `HAIKU_API_BASE_URL`. The default is for the Android emulator. For a physical device, use the development computer's LAN IP; use HTTPS in production.

Native iOS and Android project files were generated by React Native Community CLI 20.2.0 with React Native 0.88.0. Never commit signing keys, Firebase files, or API secrets.
